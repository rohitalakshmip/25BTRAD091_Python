# 25BTRAD091_Python

Python coursework, practice exercises, and project work for **25BTRAD091**.

## Repository contents

### `25BTRAD091_Lab Exercises/`

Fifteen standalone Python lab exercises, numbered 2–16, plus supporting text and CSV files used by some exercises. These cover introductory programming practice; run each exercise separately.

### `25BTRAD091_Problem Solving/`

Eighteen standalone problem-solving task scripts, along with a `25BTRAD091_Problem Solving_Mini Project/` folder containing small applications for attendance tracking, OTP generation, sales analysis, student grading, bill generation, and unit conversion.

### `25BTRAD091_Experiential Learning Activity/`

The experiential-learning project includes **SceneGraph AI**, a Python web application for screenplay scene analysis and production planning. Its project folder contains the application, core modules, tests, documentation, and static web assets. See its [project README](<25BTRAD091_Experiential Learning Activity/SceneGraph-AI/README.md>) for features and setup instructions.

## Running the exercises

Install Python, then run an exercise from the repository root. For example, in PowerShell:

```powershell
python "25BTRAD091_Lab Exercises\25BTRAD091_Lab Exercise_2.py"
```

Some exercises and projects need input files or additional packages. Check the relevant project documentation and `requirements.txt` before running them.

## Privacy and generated files

Local environment configuration, virtual environments, caches, and the SceneGraph local database are excluded from Git. Coursework data files containing personal names, compensation, or student scores are also kept local and are not published.
