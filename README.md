# 25BTRAD091_Python

Python coursework and projects for **25BTRAD091**.

## Repository contents

- **25BTRAD091_Lab Exercises/** — Python lab exercise scripts and supporting files.
- **25BTRAD091_Problem Solving/** — problem-solving task scripts and mini-projects.
- **25BTRAD091_Experiential Learning Activity/** — experiential learning project work, including the SceneGraph Production application.

## Getting started

The exercises are standalone Python files. Run an exercise with Python from a terminal:

```powershell
python "25BTRAD091_Lab Exercises\25BTRAD091_Lab Exercise_2.py"
```

For project-specific setup and dependencies, see the README in that project's folder.
